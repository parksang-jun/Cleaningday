## 이 버전의 새로운 기능 — 한국어
```
• 힌트대로 닦아도 지워지지 않던 판을 고쳤어요.
• 배경이 실제 사진처럼 바뀌고, 판마다 다른 모습이에요.
• 먼지·얼룩이 종류별로 또렷하게 보여요.
• 걸레, 스펀지, 분무기 소리가 각각 달라졌어요.
• 글씨가 더 크고 읽기 쉬워졌어요.
```

## What's New — English (U.S.)
```
• Fixed stages where following the hint did not clean the mess.
• Realistic photo backgrounds, with a different look on every stage.
• Dust and stains are easier to tell apart.
• The cloth, sponge and spray bottle each have their own sound.
• Bigger, easier-to-read text.
```
