# 1.3 출시 메모

App Store Connect: 버전 1.3 (1.2.1 이 아직 출시 전이면 그 페이지의 버전 번호를 1.3 으로 고친다) → 빌드 26.
Play Console: 비공개 테스트 → 새 버전 → versionCode 18 (1.3).

## 이 버전의 새로운 기능 — 한국어
```
• 더 시원하게 닦여요. 한 번 문지를 때 더 많이, 가장자리까지 깨끗하게 지워져요.
• 청소 화면이 가로로 더 넓어졌어요.
• 뒤쪽 판일수록 여러 가지 오염이 섞여 나와요. 도구와 세제를 골고루 써 보세요.
• 스팀 청소기와 매직블럭이 제 역할에 맞게 바뀌었어요. 타일·스테인리스에서는 더 강하고, 나무·페인트에는 쓸 수 없어요.
• 랭킹이 생겼어요. 모은 별로 다른 사람들과 겨뤄 보세요.
• 친구에게 추천하면 하루 한 번 코인을 받아요. 친구는 초대 코드로 코인을 받아요.
• 코인 쓸 곳이 늘었어요: 프로 장비 빌려 다시 하기, 별 3개 재도전, 막힌 판 건너뛰기.
• 상점에서 구매하면 바로 확인 알림이 떠요. 버튼도 커졌어요.
```

## What's New — English (U.S.)
```
• Cleaning feels snappier: each swipe removes more, right up to the edge.
• The cleaning area is wider.
• Later stages mix more kinds of mess, so every tool and cleaner gets used.
• The steam cleaner and magic eraser now do what they do best: stronger on tile and steel, not for wood or paint.
• New leaderboard: compete on total stars.
• Tell a friend for a daily coin bonus. Friends get coins with your invite code.
• More ways to use coins: rent pro gear for a retry, go for 3 stars, or skip a stage you're stuck on.
• Purchases in the shop now show a confirmation, and the buttons are bigger.
```
