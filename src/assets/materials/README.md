# 재질 사진 (CC0)

여기에 `wood.webp`(또는 `.jpg`) · `tile.*` · `steel.*` 를 넣으면 게임이 해당 재질의 결·무늬를 사진에서 가져온다. 없으면 지금처럼 캔버스로 만든 무늬를 쓴다(앱은 그대로 동작).

규칙
- **CC0(무료·상업용·출처 표기 불필요)** 사진만: Poly Haven(polyhaven.com), ambientCG(ambientcg.com). 다른 사이트 사진 금지.
- Diffuse(색) 맵 1장만, 1K(1024px) 이하, webp 권장(용량 목표 장당 150KB 이하).
- 나뭇결은 **결이 가로로 흐르게** 돌려서 넣는다(게임이 널판 방향에 맞춰 다시 돌린다).
- 색은 신경 쓰지 않아도 된다: 회색으로 바꾸고 평균 밝기를 맞춰 '결'만 쓴다(`grayCentered`). 장면 색은 코드의 색이 정한다.
- 넣을 때 아래 표에 출처를 적는다.

적용 순서(결재 graphics-assets=photo-cc0): 마루(wood) → 타일(tile) → 스테인리스(steel). 현재 코드는 **마루(wood)** 가 연결돼 있고 tile·steel 은 자리만 있다.
