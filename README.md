# 싹싹 클린 (Sparkle Clean) — 청소 캐주얼 게임

Jelly Blocks(블록 퍼즐)를 대체하는 2027 출시용 광고 수익형 게임. 손가락으로 문질러 오염을 지우는 "보는 맛" 캐주얼 게임이며, **나중에 실제 청소 도구·세제 광고주가 들어오면 그 제품의 실제 성능과 기능대로 게임 속에서 청소되도록** 설계했다.

## 1. 게임 규칙 — 맞는 도구·세정제를 찾아야 지워진다

- **오염 12종 × 표면 12종 × 도구 18종 × 세정제 15종.** 오염마다 실제 청소와 같은 "레시피"(맞는 도구군 + 필요한 세정제군, 표면 조건)가 있고(`src/game/catalog.ts` `RECIPES`), **맞지 않는 조합은 아무리 문질러도 0** — 커서가 붉게 흔들리고 이유가 뜬다(틀린 도구 / 세정제 필요 / 틀린 세정제 / 이 표면엔 안 됨). 플레이어는 보유한 여러 도구·세정제를 시험해 맞는 조합을 찾고, 찾은 조합은 **청소 수첩(📖)** 에 영구 기록된다.

  | 오염 | 통하는 조합 (기본 장비) | 안 통하는 예 |
  |---|---|---|
  | 먼지 | 청소기 · 극세사 걸레(패브릭 제외) · 돌돌이(패브릭) · 호스/고압(실외) | 스펀지, 솔 |
  | 머리카락·먼지뭉치 | 청소기 · 돌돌이(패브릭) | 걸레(밀어낼 뿐) |
  | 마른 진흙 | 젖은 스펀지 · 호스/고압 · 데크 솔 · 카샴푸+워시미트 · 패브릭은 청소기 | 마른 걸레 |
  | 기름때 | 기름때 제거제 + 수세미/스펀지 (원목은 중성세제+걸레로 천천히, 비닐은 실내 클리너) | 세정제 없이 문지르기, 유리세정제 |
  | 얼룩 | 다목적 세정제 + 걸레/스펀지 · 패브릭은 패브릭 클리너 · 유리는 유리세정제 | 패브릭에 다목적 세정제 |
  | 물때 | 물때 제거제(산성) + 스펀지/타일 솔 · 유리는 +스퀴지 · 휠은 휠 클리너 | 욕실 세정제(느림) |
  | 비누때 | 욕실 세정제 + 스펀지/타일 솔 | 물때 제거제(느림) |
  | 곰팡이 | 곰팡이 제거제(염소계) + 타일 솔 — 뿌려 두면 저절로 녹음 · 원목/플라스틱/패브릭은 산소계 데크 클리너 | 원목에 염소계(손상) |
  | 이끼 | 고압세척기(석재·벽돌·도장) · 이끼 제거제 + 데크 솔 · 데크 클리너(원목) | 원목에 고압(손상) |
  | 브레이크 분진 | 휠 클리너 + 휠 브러시 | 카샴푸 |
  | 타르·벌레 | 타르 제거제 + 걸레/워시미트 | 카샴푸 |
  | 지문·유막 | 유리세정제 + 스퀴지(빠름)/걸레 · 비닐은 실내 클리너 · 그 외 다목적 세정제 | 마른 걸레(번짐) |

- **프리미엄(빨리 닦는 장비)** 은 상점에서 코인으로만 산다: 무선 청소기(×1.5, 더 넓게), 전동 스크러버(스펀지·수세미·타일솔·휠브러시 군 ×2), 드릴 브러시(×2.1), 스팀 청소기(세정제 없이 기름때·얼룩·비누때·유막·곰팡이), 매직 스펀지(세정제 없이 얼룩·유막·비누때), 강력 기름때 제거제(×1.8), 물때 젤(×1.8, 저절로 녹음). 각 제품은 실제 판매 제품군과 1:1 대응해 판매몰 링크로 이어진다.
- **안내 단계는 3단계까지** (`GUIDED_UNTIL`): 1~3단계에서만 툴바에 그 판에 필요한 아이템만 나오고(`stageKit()`), 틀린 이유("세정제를 먼저 뿌려보세요" 등)를 알려 주고, 한 오염에 두 가지 이상 실패하면 수첩에서 보상형 광고 또는 코인 30으로 힌트(먼저 세정제, 다음 도구)를 연다. **4단계부터는 힌트가 없다**: 필요한 아이템에 "솔깃한" 미끼 도구·세정제 2~4개(단계가 오를수록 많이, 그 판의 오염에 통할 듯한 것 우선)가 섞여 나오고, 틀리면 "효과 없음"만 알려 준다. 막혔을 때 유일한 안내는 **쇼호스트의 광고 제품 소개**(아래) — 광고가 곧 힌트다. 시계(제한시간)는 첫 효과(분사·제거)가 나야 돌기 시작해 도구를 고르는 시간은 세지 않는다.
- **찌든 때와 고성능 장비** (`TAIL_AMOUNT`·`tailRate`·`pro`): T3부터 칸의 마지막 35% 층은 "눌어붙은" 찌든 때라 기본 도구로는 단계별 0.7→0.55배 속도로 더디게 지워진다. **고성능(pro) 장비 — 코인으로 산 프리미엄과 성능 근거가 있는 광고 제품(일반 대비 1.15배 이상, 또는 닦는 면적 1.15배 이상)** — 는 끝까지 같은 속도로 지우고, 세정제 용량 1.5배, 그리고 지운 칸에 **광택 마감**(은은한 광 + 반짝임)을 남긴다. 결과 화면에 "✨ 광택 마감 n%"와 보너스 코인(50% 이상일 때 10×비율×단계)이 붙는다. 목표·제한시간은 기본 장비 봇 기준이라 고성능 장비를 쓰면 실제로 더 쉽고 더 깨끗하다(`npm test`: 프리미엄 장비가 평균 1.6배 빠르고 광택 ≥30%).
- **스테이지 모드 6종** — 같은 닦기라도 목표와 긴장이 다르다. 모든 스테이지에 테마 제목(파티 다음 날 · 비 온 뒤 · 고양이 털 날리는 날 · 정전 · 장마철 · 세입자 나간 날 …)이 붙는다.

  | 모드 | 규칙 | HUD |
  |---|---|---|
  | 청소하기 `clean` | 기준 % 이상 닦기 | — |
  | 끈질긴 얼룩 `spots` | 표적 링으로 표시된 얼룩 3~6곳을 완전히(아래층까지) 지우기 | 🎯 n/N |
  | 계속 생겨요 `rush` | 닦는 동안 발자국·털·튄 기름·벌레 자국이 N번 더 생김 — 다 생긴 뒤 기준 달성 | 🐾 +n |
  | 번지는 중 `spread` | 곰팡이·이끼가 가장자리로 번짐(최대 1.6배) — 세정제가 닿은 칸은 멈춤 | 🦠 |
  | 민감한 표면 `fragile` | 손상 10% 면 즉시 실패(광고 연장 없음) — 유리·원목·비닐·플라스틱 | ⚠ 손상 % |
  | 불이 꺼졌어요 `dark` | 손전등(커서) 반경 안만 보임, 목표시간 1.3배 | 🔦 |

- **96단계 · 3개 월드 · 7개 구역** (`src/game/levels.ts`): 아파트(거실 1~12 · 방 13~24 · 주방 25~36 · 화장실 37~48) → 단독주택 정원(49~72: 테라스·데크·벽돌 외벽·정원 의자·울타리·그릴) → 자동차(실외 73~84: 보닛·앞유리·휠·헤드라이트 / 실내 85~96: 시트·대시보드·바닥매트·트렁크). 새 오염이 처음 나오는 판에 맞는 아이템을 다른 후보와 함께 지급한다.
- **난이도 6단계(T1~T6)** 가 규칙을 하나씩 더한다:

  | 단계 | 스테이지 | 새 규칙 | 통과 기준 | 제한시간 | 세정제 용량 |
  |---|---|---|---|---|---|
  | T1 | 1~12 | 맞는 도구 찾기, 오염 1~3종 (1~3단계만 안내·힌트) | 90% | 없음 | 무제한 |
  | T2 | 13~24 | 겹친 오염(윗층 아래 다른 종류) | 93% | 목표×2.6 | 무제한 |
  | T3 | 25~36 | 세정제가 꼭 필요한 오염(기름때·물때), 찌든 때 ×0.7 | 95% | 목표×2.3 | 세정제당 18초 |
  | T4 | 37~48 | 곰팡이·비누때, 염소계↔산성 헹굼, 찌든 때 ×0.65 | 96% | 목표×2.1 | 16초 |
  | T5 | 49~72 | 실외 도구(호스·고압), 이끼, 찌든 때 ×0.6 | 97% | 목표×1.9 | 14초 |
  | T6 | 73~96 | 전용 세정제 4종, 오염 최대 6종, 찌든 때 ×0.55 | 98% | 목표×1.75 | 12초 |

  오염 양은 구역 배수(거실 1.0 → 정원 2.25)와 진행도로 늘어난다. **목표·제한시간은 레시피를 다 아는 숙련자 봇(`src/game/bot.ts`)의 시간 × 단계 배수**로 정해져 기기와 무관하게 같다. `npm test` 의 난이도 테스트가 96판 모두 봇이 보유 장비로 손상·위험 없이 깰 수 있고(레시피·지급 설계 검증), 단계·구역 평균 시간이 단조 증가하는지 검사한다(봇 기준 T1 21초 → T6 69초; 목표 배수는 T1 1.8 → T6 1.2로 좁아진다).
- **오염 질감** (`src/render/grime.ts`): 종류별 고해상도 "때" 텍스처를 판마다 한 번 그려 두고(먼지 보풀·실오라기, 머리카락 가닥, 갈라진 마른 진흙과 튄 방울, 번들거리는 기름과 탄 자국·흘러내림, 커피·와인 링, 석회 결정과 물 자국, 비누때 물방울 자국, 곰팡이 점 군집, 이끼 포기, 브레이크 분진 알갱이, 타르 방울과 벌레 자국, 지문 소용돌이), 격자 농도를 **비틀린 위치에서 겹선형 보간한 마스크**로 잘라 쓴다 — 칸 격자가 보이지 않는 울퉁불퉁한 얼룩 윤곽. 오염이 바뀔 때만 다시 합성(≤40Hz, 레이어 ≤1.15MP).
- **쾌감**: 닦는 궤적이 하얗게 빛나고(액체 도구는 젖은 광택이 잠시 남음), 지워진 자리에서 종류별 파편이 튄다(먼지 뭉게구름·머리카락이 청소기로 빨려 들어감·진흙 조각·기름 방울·석회 조각·비누 거품·이끼 포기·분진·타르 방울). 남은 오염만큼 장면 전체가 칙칙하다가 닦을수록 환해지고, 25·50·75% 를 넘을 때마다 빛이 쓸고 지나가며 "샤란" 소리. 지울 때마다 반짝임, 연속으로 지우면 **콤보(×N)** 가 올라 반짝임이 황금빛으로 바뀌고 소리가 높아진다. 한 오염 종류를 다 지우면 "싹!" 팝업과 소리, 조합을 찾으면 발견 팡파르, 클리어 시 **더러운 화면 → 깨끗한 화면 전후 리빌** 애니메이션 뒤 결과가 뜬다. 격자는 56×72.
- **소리** (`src/audio.ts`, 파일 없이 WebAudio로 합성): 첫 터치에서 오디오를 깨우고(브라우저 자동재생 정책, iPhone 무음 스위치 우회 포함) 도구마다 다른 문지르는 소리(걸레·스펀지·솔·청소기·물·고압세척기·스퀴지·스팀·돌돌이·미트), 이벤트 소리(분사·반짝·발견·싹·실패·코인·구매·시작·마지막 10초 째깍·위험 경고), 잔잔한 배경음악(펜타토닉 생성 멜로디, 플레이 중엔 작아짐). 설정에서 효과음·배경음악을 따로 끌 수 있다.
- 표면 손상(수세미·타일솔을 유리·도장·원목·플라스틱에, 염소계를 원목·패브릭·도장·플라스틱·금속에 …), 위험 혼합(염소계+산성), 별 3개 기준(목표 시간·손상 15% 미만·위험 혼합 없음), 코인 = (20 + 별×10) × 난이도 단계.
- 광고 위치: 결과 "코인 2배", 상점·쇼호스트 "이번 판 무료 체험"(광고 제품·프리미엄), 수첩 "힌트"(1~3단계), 시간 초과 "+30초", 세정제 소진 "리필" (보상형) + 결과 후 전면 광고(첫 판 제외, 2판·150초 간격 — `src/ads/index.ts`).
- **재오염 — 청소하는 동안 누가 자꾸 어지럽힌다** (`levels.ts` `messFor()`, `engine.ts` `messOne()`): **4단계부터 러시 모드를 뺀 모든 판**에 장면별 "어지럽히는 이"가 붙는다 — 🧒 아이들(바닥·러그·매트: 발자국 줄), 🐾 반려동물(소파·침대·시트: 털 줄), 🍳 튀는 기름(가스레인지·싱크·그릴·식탁), 🌬️ 내려앉는 먼지(창문·선반·거울·대시보드·앞유리: 옅고 넓게), 💦 물튀김(욕실), 🍂 낙엽·흙(정원), 🐦 새·벌레(자동차 외부). 생기는 오염은 **그 판에 이미 있는 종류**라 지울 도구가 반드시 있다(곰팡이·이끼·녹은 "자라는" 것이라 재오염으로는 안 생김). 시작 후 `after`초(T1 12 → T6 6)부터 `every`초(14 → 7)마다, 한 번에 처음 오염량의 3~6%, 총 20~40%까지(횟수도 ⌈cap/amount⌉로 상한) — 세정제를 뿌려야 하는 기름·물때는 양을 줄이고(×0.7/×0.55), 바깥 흙·새똥은 더(×1.25). 1.2초 전 예고 배너 → 떨어지는 파편·흔들림·진행률 하락, HUD 에 다음 발생 카운트다운. **목표시간은 재오염을 절반만 반영**(`MESS_PAR_WEIGHT`): 나머지 절반은 플레이어 여유를 갉아먹어 빨리 끝내거나 좋은 장비를 쓸 이유가 된다(봇 기준 기본 장비 +18%, 프리미엄 장비는 어지럽혀져도 조용한 기본 장비보다 28% 빠름). 결과 화면 "재오염 N번 — 빠른 장비일수록 덜 당해요", 상점 프리미엄 소개문도 같은 말. 디버그 `__sparkle.mess() / forceMess() / setShield(sec)`.
- **장비 추천 — "이런 도구를 쓰면 청소가 더 빨라지고 깨끗해져요"** (`src/gear.ts`, main.ts `maybeGearTip()`): 판 안에서 **느리게 가는 중**(목표시간의 절반이 지났는데 반도 못 닦음)이거나 **재오염을 두 번째** 당했을 때, 지금 남은 오염 중 가장 많은 것·그 표면에 맞는 **코인 구매 프리미엄 장비 하나**를 `premiumFor(dirt, surface, owned)` 로 골라(기본 장비 대비 배속·세정제 불필요·넓게 닦음 배지, 표면을 상하게 하는 장비 제외, 도구 우선 → 세정제) 뽀득이 카드로 설명한다. 코인이 되면 **"바로 구매"** → 툴바에 장착되고 바로 선택, 모자라면 **"광고 보고 +80"** → 채워지면 구매 버튼으로 다시. 한 판에 한 번, 판 사이 90초 쿨다운, 4단계부터, 쇼호스트·모달이 떠 있으면 안 뜸, 14초 뒤 자동 닫힘. 시간 초과 화면에도 "다음엔 {장비}로 — {오염}이 N배 빨리" 한 줄. 이벤트 `gear_tip{reason: slow|mess|fail}` · `shop_buy{via: gear_tip}`. 디버그 `__sparkle.gearTip(reason, dirt?) / setCoins(n)`.
- **코인 경제** (`src/economy.ts`) — 광고로 받은 코인에 "쓸 곳"이 있어야 광고를 본다.
  - **광고 제거 이용권**(코인): 1일 300 · 7일 1,500 · 30일 5,000 — 기간 동안 판 사이 전면 광고와 저절로 뜨는 쇼호스트 광고가 없다(남은 기간 위에 쌓임, `ads.adFreeUntil`). 보상형 광고는 원할 때 보는 것이라 그대로 — 코인을 벌어 광고를 끄는 순환. 이벤트 `adfree_buy`.
  - **쇼호스트 광고는 판마다 한 번**: 판 시작·막힘·결과 중 저절로 뜨는 소개는 한 판에 한 번만(`GameState.hostAuto`). 수첩·결과 화면 버튼·상점 라이브처럼 직접 누른 소개는 예외.
  - **벌기**: 판 클리어 코인 · 결과 화면 "광고 보고 코인 2배" · 상점 **"광고 보고 +80 코인"(하루 5회)** · **매일 첫 접속 보너스** 30 + 연속 접속일×10(최대 80).
  - **쓰기 — 부스터**(판 안 HUD 바, 1회용): ⏱ **시간 연장** +20초(60코인) · 🫧 **거품 폭탄** 남은 오염 20%를 칸 단위로 한 번에 제거(120코인, `engine.blast()`) · 🔎 **오염 스캔** 이 판의 모든 오염에 맞는 도구·세정제를 12초간 보여 주고 수첩에 기록(50코인) · 🛡 **재오염 차단** 25초 동안 아무도 어지럽히지 못함(80코인, `session.shield()`). 코인이 모자라면 **"광고 보고 1개"(하루 3회)** — 코인이 부족한 순간이 곧 광고 접점.
  - **쓰기 — 이어하기**: 시간 초과 화면에서 광고(+30초) 또는 **코인 100(+20초)**. 그 밖에 수첩 힌트 30, 프로 장비 400~1200(영구).
  - 빈 부스터 칸을 누르면 상점이 열리고, 홈의 코인 수와 결과 화면의 "코인은 상점에서…" 링크도 상점으로 간다. 일일 카운터는 날짜가 바뀌면 초기화(`daily()`), 이벤트 `booster_buy / booster_ad / booster_use / coins_ad / daily_bonus / level_extend{coins}`.

## 2. 스폰서(광고주) 제품 = 실제 성능대로 청소

`src/game/sponsor.ts` 가 광고주 제품의 **시험 성적**을 게임 성능으로 바꾼다.

| 원칙 | 구현 |
|---|---|
| 근거만으로 성능 결정 | 오염별 `제거율(%) ÷ 같은 시험의 일반 기준 제품 제거율` = 배율. 근거 없는 오염은 1.0(일반 제품과 동일) |
| 과장 방지 | 배율 0.5~1.8로 제한, 성적서·시험기관·날짜 없으면 노출 안 함(`validateSponsor`) |
| 기능 반영 | 도구는 1분당 닦는 면적 → 브러시 반경, 세제는 화학 계열(염소·산·알칼리·중성) → 위험 혼합 규칙 |
| 라벨 주의사항 반영 | 제품 라벨의 사용 금지 재질 → 게임에서도 그 표면에 쓰면 손상 |
| 광고 표시 | 툴바·상점에 "광고" 배지, 성능 근거 화면(시험기관·성적서·방법·오염별 일반 제품 대비 %) |
| 캠페인 | 시작/종료일 밖이면 자동 숨김 |

현재는 **가상 브랜드 샘플 2종**(BrightMax 기름때 제거제, AquaJet 무선 고압세척기)이 "샘플·가상 브랜드" 표시와 함께 들어 있다. 실제 광고주가 오면 `SAMPLE_SPONSORS` 를 원격 설정(예: Supabase 테이블·Remote Config)에서 받아오도록 바꾸고 샘플은 삭제한다.

### 광고주 제출 자료 (온보딩 스펙)

```ts
{
  id, brand, name,
  kind: 'tool' | 'detergent',
  base: ToolId | DetergentId,                       // 기본 계열 중 하나 (프리미엄 계열 불가) — 레시피는 계열로 판정

  lab: [{ dirt: 'grease', removalPct: 92 }, ...],   // 오염별 제거율 — 시험 방법을 명시한 성적서 필수
  coverageM2PerMin?: 7.5,                           // 도구: 1분당 처리 면적
  chemistry?: 'neutral' | 'alkaline' | 'acid' | 'chlorine',
  cautions: ['wood', 'paint'],                      // 라벨의 사용 금지 재질
  evidence: { lab, reportId, date, protocol, url? },
  campaign: { start, end },
}
```

- `REFERENCE_REMOVAL`(일반 기준 제품 제거율)은 현재 가정값이다. **출시 전 운영사가 같은 시험 방법으로 무브랜드 제품을 직접 시험해 갱신**해야 광고주 간 비교가 공정해진다.
- 게임 속 성능 표현도 광고에 해당하므로 표시광고법상 **실증 책임**이 생긴다. 성적서 원본 보관, "업계 최고" 같은 비교 우위 문구 금지(근거 없는 경우), 출시 전 법률 검토 권장.

### 진짜 청소 꿀팁 (`src/game/tips.ts`)

### 세정제 섞어 쓰기 (`MIXES`, `engine.spray()`)

세정제가 아직 남아 있는 칸에 **다른 세정제를 겹쳐 뿌리면 혼합물**이 된다(`findMix`). 진짜 레시피대로 섞어야 제맛인 조합은 **단독보다 강한 세정제**가 되고(베이킹소다+주방세제 `soapsoda` 1.05~1.1배, 식초+주방세제 `soapvinegar` 유리 1.4배), 혼합물은 툴바 아이템이 아니라 뿌린 자리에만 존재하며 수첩에는 `기름때|수세미|soapsoda` 처럼 제 조합으로 기록된다. 혼합물 위에 그 재료를 더 뿌려도 유지되고(시간만 연장), 제3의 세정제를 뿌리면 덮인다. 베이킹소다+식초(구연산)는 **중화 조합**: 흰 거품이 솟고 "섞지 마세요" 팁 팝업이 한 번 뜬 뒤 그 자리는 세정력 0 이 된다(`neutralized`). 락스+산·산소계는 혼합물이 아니라 종전대로 **위험 혼합 경고**다. 가져온 세정제 둘이 섞이는 조합이면 인트로에 "겹쳐 뿌리면 섞여요" 규칙 한 줄이 뜨고(어떤 조합인지는 알려 주지 않음), 섞어 쓴 레시피를 하나라도 수첩에 적으면 사라진다.

거품은 **뿌린 자리에만** 생긴다: 거품 질감을 `destination-in` 으로 분사 마스크 안에 가두고(전에는 텍스처가 화면 전체에 깔려 뿌옇게 보였다), 반투명(최대 약 45%)이라 아래 오염이 비쳐 어디를 문지를지 보인다. 액체 도구의 젖은 자국은 점마다 겹쳐 그리지 않고 한 획으로 그려 밝기가 쌓이지 않는다. 혼합물은 색으로 구분(페이스트 크림색, 식초+세제 연두, 중화 거품 흰색).

### 3D 보기 (`src/render/view3d.ts`, three.js r170)

**기본은 2D** 이고 3D 는 실험 기능으로 코드에만 남겨 두었다(UI 에 전환 없음, `settings.use3d` / 디버그 훅 `__sparkle.force2d(false)` 로만 켬). 게임 규칙·엔진은 그대로이고, 2D 렌더러가 그린 오염·거품·반짝임 캔버스를 **청소 대상 면의 텍스처**로 쓴다. 표면 방향에 따라 바닥형(마루·러그·싱크·욕조·테라스 — 눕혀서 위에서 비스듬히), 벽형(창문·거울·타일 벽·냉장고·차 문 — 세워서), 기울어진 면(앞유리·대시보드)으로 놓고, 장소마다 방(벽·걸레받이·화분), 주방 상판, 욕실 타일 띠, 정원(하늘·나무), 자동차(차체·바퀴)를 둘러 세운다. 포인터는 광선 투사로 면의 UV → 격자 좌표로 바뀌어 2D 와 똑같이 닦이고, 손끝에는 **도구 계열별 3D 모형**(스펀지·걸레·솔·청소기·스퀴지·물총/고압/스팀 건·분무기)이 따라다니며 문지르면 눌리고 흔들린다. 카메라는 면이 화면을 채우도록 거리를 맞추고 포인터 쪽으로 살짝 기운다(시차). three.js(약 124KB gzip)는 판에 들어갈 때 지연 로드하고, WebGL 이 없는 기기에서만 조용히 2D 로 돌아간다.

### 청소 소리 — 대상에 따라 다르게 (`src/audio.ts`)

문지르는 소리는 **도구 × 표면 재질 × 오염**으로 합성한다(오디오 파일 없음). 도구 프로필(걸레 스윽·솔 북북·청소기 윙·물 쏴·고압 쐐·스퀴지 끽·스팀 치익·돌돌이 찍찍) 뒤에 **표면 재질의 공명 필터와 울림음**을 건다 — 나무 둔탁(420Hz, 180Hz 울림)·타일 쨍(2.6kHz)·도기 맑음(3kHz)·유리 끽(3.6kHz, 젖으면 뽀드득 강조)·강철/금속 챙(삼각파 울림)·천 먹먹(로우패스)·돌/벽돌 서걱·도장면 매끈·플라스틱 속 빈 소리. 손가락 주변 3×3 에 **오염이 남아 있으면 질감 레이어**를 얹는다 — 먼지·진흙 자글자글(grit), 머리카락·이끼 바스락(rustle), 기름·얼룩·타르·유막 질척(squelch, LFO 가 로우패스를 흔드는 와우), 물때·녹·곰팡이 긁힘(scrape), 비누 거품 보글(fizz). 오염이 없어지면 질감이 꺼지고 울림음만 또렷해져 "다 닦였다"가 소리로 들린다. 재질·오염 경계를 오갈 때 160ms 동안은 노드를 다시 만들지 않아 깜빡이지 않는다. 디버그 `__sparkle.audio().scrubKey` = `도구:재질:질감`.

### AI 쇼호스트 "뽀득이" (`src/host.ts`, `src/avatar.ts`)

쇼호스트 얼굴은 세 소스 중 있는 것을 쓴다. ① **운영자가 올린 실사 영상**(제품별 `hostVideo`: HeyGen·D-ID·Synthesia 같은 AI 아바타 서비스로 만든 영상이나 실제 촬영본, https URL 또는 테스트용 파일 업로드→IndexedDB `idb:` 참조) — 영상이 재생되고 영상 음성이 목소리가 된다(소리 있는 자동재생이 막히면 음소거 재생 + TTS). ② **운영자가 올린 실사 사진**(전역 `host.photo` 또는 제품별 `hostPhoto`, 업로드 시 정사각형 420px JPEG data URL 로 압축) — 라이브 카드에 사진 + 말할 때 링 펄스 + 느린 줌, 목소리는 TTS. ③ 둘 다 없으면 **내장 마스코트 '뽀득이'**: `tools/host-portrait.py` 가 그린 청소 거품 구름 캐릭터(만화 스타일 — 진청록 외곽선, 큰 청록 눈, 분홍 볼, 민트 분무기·노란 고무장갑·헤드셋·반짝이; 사람 얼굴이 아니라 언캐니 밸리도 초상권 문제도 없다) 9장 레이어(`src/assets/host/*.webp`) — 눈 뜸/반/감음(^ ^), 입 닫힘/중간/벌림, 눈썹, 헤드셋 — 을 겹쳐 깜빡임·립싱크·눈썹 강조·호흡을 애니메이션한다. 기본 이름은 뽀득이(Squeaky / ピカリン), 운영자 모드에서 바꿀 수 있다. 캐릭터를 바꾸려면 스크립트 상단 덩어리 좌표·색 상수를 고치고 다시 실행. 관리자 모드 "쇼호스트" 탭에 사진 업로드와 **실사 영상 만드는 법**(대본 복사 → AI 아바타 서비스 → URL 입력)이 있고, 제품 편집 화면의 **"멘트 복사"**가 한/영/일 대본을 클립보드로 준다.

멘트는 **전문가 톤**으로 ① 인사 ② (결과 화면) 이번 판에 직접 썼다/같은 종류를 썼다 ③ 그 오염의 원리(꿀팁의 전문가 한 줄) ④ 광고주 시험 수치 ⑤ 소구점 ⑥ 리뷰 ⑦ 라벨 주의 재질 ⑧ 제안 순으로 자동 생성되고, 운영자가 직접 쓴 멘트가 있으면 ④~⑥을 대신한다. 음성은 기기 TTS(`speechSynthesis`, ko/en/ja 목소리 자동 선택, 설정에서 끔), 자막은 타자 효과.

**실제 판매 제품(제휴 추천)** (`src/game/realProducts.ts`): 유료 광고주(시험 성적 있음)가 없는 자리에는 쇼호스트가 **실제로 팔리는 제품**을 소개한다 — 한국(쿠팡) 유한락스 레귤러·홈스타 곰팡이싹 젤·피죤 무균무때·3M 스카치브라이트·매직블럭·다이슨 V12·카처 K2·한경희 스팀청소기, 미국(Amazon) Mr. Clean Magic Eraser·Scotch-Brite·CLR·Windex·Tilex·Dyson V8·Kärcher K1700·Meguiar's·Bissell SteamShot, 일본(Amazon.co.jp) 花王 マジックリン·カビキラー·激落ちくん·茂木和哉·ガラスマジックリン·ケルヒャー·シュアラスター·スコッチ・ブライト. 원칙: 시험 성적이 없으므로 **게임 아이템이 되지 않고**(성능 변화 없음, 체험 버튼 없음) 멘트는 **라벨의 용도·주의만**(효능 수치·비교 금지, 단위 테스트로 검사), 카드에는 **"광고" 배지와 "광고 · 제품 설명은 라벨 기준"** 만 표시(수수료 문구는 카드·음성에 넣지 않음 — 판매몰 탭도 같음. 쿠팡 파트너스·Amazon Associates 약관의 고지 문구(`coupangDisclosure`·`mallDisclosure`)는 i18n 에 남겨 두었으니 출시 전 스토어 설명·개인정보 페이지 등에 넣을 것) + "쿠팡에서 보기"(언어권 마켓). 수익은 구매 수수료: 링크는 관리자 패널 "구매 링크"에 **쿠팡 파트너스·Amazon Associates 에서 만든 링크**를 붙여 넣는다(비우면 마켓 검색 링크 — 동작은 하지만 수수료 없음; `VITE_COUPANG_LPTAG`·`VITE_AMAZON_TAG_US/JP` 가 있으면 검색 링크에도 태그가 붙음). 운영자 설정 "실제 판매 제품 소개"로 끄고 켤 수 있고(`HostConfig.affiliate`), 판매몰 탭에도 같은 제품이 마켓별로 나온다. 유료 광고주는 우선순위가 높아 같은 자리에서 먼저 나온다.

**실제 제품을 게임에서 체험**: 실제 제품은 체험 가능한 게임 아이템(`sp:<id>`)이 된다 — 성능 = **제품 유형의 기준 아이템**(다이슨 → 무선 청소기, 스팀 청소기, 멜라민 스펀지 등) × **공개 사양 배율**(다이슨 V16 흡입력 315AW ÷ V15 240AW → ×1.15, 카처 K4 130bar ÷ K2 110bar → ×1.18). 세정제는 효능 시험값이 없어 유형 기준 그대로. 카드에 근거 사양(⚡ 315AW)과 "광고 보고 이번 판 무료 체험"이 붙고, 체험하면 도구함에 들어와 바로 선택된다. 제품은 확인 가능한 최신 모델로(다이슨 V16 피스톤 애니멀, 카처 K4 컨트롤 플렉스/Power Control/サイレント).

**관리자 테스트 플레이** (관리자 → "테스트 플레이" 탭): 96판 전체 목록에서 아무 판이나 바로 시작(진행 저장은 그대로), 코인 +1,000·부스터 각 +5·프리미엄 장비 전부 지급/해제, "게임 화면에서도 모든 판 열기"(🛠 표시, 관리자 빌드에서만).

**사람 목소리**: 제품별·언어별 **음성 파일**(`hostAudio.ko/en/ja`: https mp3 또는 관리자 업로드 `idb:`)이 있으면 브라우저 TTS 대신 재생하고 자막을 음성 길이에 맞춰 넘긴다(자동재생이 막히면 TTS 로 대체). 만드는 법: 관리자 "멘트 복사" → 클로바 더빙·타입캐스트·ElevenLabs 에서 mp3 → 언어별 업로드, 또는 `npm run voice -- <제품id> <ko|en|ja>` (`ELEVENLABS_API_KEY` 또는 `GOOGLE_TTS_API_KEY`; 키가 없으면 대본만 출력). 음성 파일이 없을 때의 브라우저 TTS 는 신경망·온라인·향상 목소리(iOS "유나(향상됨)", Android Google 온라인 음성 등)를 점수로 골라 쓰고 음높이를 기본값으로 둔다 — iOS 에서는 설정 > 손쉬운 사용 > 음성 콘텐츠에서 향상된 한국어 음성을 받아 두면 눈에 띄게 자연스럽다.

**매 판 끝 광고**: 결과 화면이 뜨고 1.3초 뒤 쇼호스트가 나와 이번 판에서 ① 직접 써 본 광고 제품(체험) → ② 같은 종류의 일반 제품을 썼다면 그 광고 제품("이번 판에 기름때 제거제 쓰셨죠? 같은 종류인데…") → ③ 이 판 오염에 맞는 제품 → ④ 아무 제품 순으로 고른다(같은 등급에선 우선순위, 그다음 가장 오래전에 보여 준 것 — 돌아가며). 결과 노출은 재노출 간격·중복 제한이 없고 설정(`host.result`)으로만 끈다. 판 시작 소개(intro)의 재노출 간격은 소개 노출(`lastIntroAt`)만 세므로 결과 광고가 다음 판 소개를 막지 않는다. 광고 제품이 이 판과 무관(④)할 때만 실제 제품 추천 카드도 같이 나온다.

**사람 모습의 AI 청소 전문가**(일러스트 — 깜빡임·입 모양·호흡·눈썹 강조 애니메이션, 헤드셋·앞치마, "AI 쇼호스트" 표시)가 광고 제품을 라이브 커머스처럼 소개한다. 멘트는 **전문가 톤**으로 ① 인사 ② 그 오염의 원리(위 꿀팁의 전문가 한 줄: "기름때는 산성 지방이라 알칼리가 분해해요…") ③ 광고주 시험 수치 ④ 소구점 ⑤ 리뷰 ⑥ 라벨 주의 재질 ⑦ 제안 순으로 자동 생성되고, 운영자가 직접 쓴 멘트가 있으면 ③~⑤를 대신한다. 음성은 기기 TTS(`speechSynthesis`, ko/en/ja 목소리 자동 선택, 설정에서 끔), 자막은 타자 효과. 실사 영상급 아바타가 필요하면 출시 전 HeyGen/D-ID 류 API 로 멘트를 영상화해 같은 자리에 붙이면 된다(멘트 생성·집계는 그대로).

| 등장 위치 | 조건 | 버튼 |
|---|---|---|
| 판 시작 소개 `intro` | 이 판의 오염에 맞는 광고 제품이 있고, 시작 스테이지(기본 2) 이상, 같은 제품 재노출 간격(기본 8분) 경과 | 광고 보고 이번 판 무료 체험 · 구매(몰) · 성능 근거 |
| 막혔을 때 `struggle` | 4단계부터 한 오염에 N회(기본 2) 틀리고 아직 조합을 모를 때 — 시계가 멈추고 등장. 수첩의 "쇼호스트에게 물어보기"로도 호출 | 같음 |
| 결과 화면 `result` | 주 오염에 맞는 광고 제품이 있을 때 한 번 (재노출 간격 적용) | 광고 보고 다음 판 무료 체험 · 구매 |
| 상점 LIVE `shop` | 상점 상단 "LIVE" 줄에서 제품을 누르면 | 같음 |

광고 제품은 이제 **보상형 광고로 "이번 판 체험"해야 쓸 수 있다**(쇼호스트·상점에서). 체험한 광고 제품은 고성능(pro) 판정이면 찌든 때 보너스·광택까지 받는다. 모든 등장·클릭·체험·구매 링크는 `host_show / host_cta_trial / host_cta_buy` 이벤트로 집계되어 운영자 모드 통계에 쌓인다.

### 운영자(관리자) 모드 (`src/admin.ts`, `src/ops.ts`)

게임 모드와 분리된 운영 화면. 홈 하단 "🛠 운영자 모드" → PIN(기본 `1234`, 빌드 시 `VITE_ADMIN_PIN` 로 변경, `VITE_ADMIN=off` 면 진입점 숨김; `#admin` 해시로도 열림).

| 탭 | 기능 |
|---|---|
| 광고 제품 | 내장 샘플 + 운영자 등록 제품 목록: 노출 상태(검증 실패 사유 표시), 고성능(PRO) 여부, 노출·체험·구매 클릭·반응률, 편집 / ▶ 미리보기(쇼호스트 바로 띄움) / 일시정지·재개 / 삭제(운영자 등록만) |
| 편집 | 기본 정보(브랜드·제품명·종류·기준 계열·화학 계열·면적), 오염별 시험 제거율(기준 제품이 닦는 오염만 입력 가능), 사용 금지 재질, 성적서(시험기관·번호·일자·방법·URL), 캠페인 기간·상태·우선순위·노출 국가(KR/US/JP)·노출 위치, 소구점·리뷰 수/평점/출처, 언어별 쇼호스트 멘트(비우면 자동 생성, 자동 생성 미리보기), 구매 링크(마켓별) |
| 쇼호스트 | 켜기/끄기, 이름, 같은 제품 재노출 간격, 소개 시작 스테이지, 막힘 등장 조건, 결과 화면 추천 |
| 통계 | 스테이지 시작/완료/실패, 코인, 제품별 노출(위치별)·체험·구매 클릭·근거 열람·반응률, 원시 카운터, 초기화 |
| 배포 JSON | 제품 전체 + 쇼호스트 설정 JSON 내보내기(복사)·가져오기 — 실서비스는 이 JSON 을 원격 설정(CDN/Supabase)으로 올리고 앱이 시작 시 받아오면 된다 |

운영 데이터는 지금은 기기 로컬(`store.ops`)에 저장된다. 출시 시에는 운영자 모드를 별도 웹 빌드(`VITE_ADMIN=on`, 게임 빌드는 `off`)로 띄우고, 집계는 서버 분석(Firebase/GA4)으로 교체한다. 표시·광고법: 쇼호스트 멘트와 소구점에는 **근거 자료가 있는 문구만** 입력한다 — "100% 박멸" 같은 절대 표현은 시험 성적서가 뒷받침할 때만.

## 2b. 실제 제품 판매몰 (`src/mall.ts`)

상점의 **"실제 제품" 탭**과 결과 화면의 "이 오염에 맞는 실제 제품" 카드, 스폰서 근거 화면의 구매 버튼이 실제 쇼핑몰로 연결된다. 가격·재고는 앱에 표시하지 않고 판매몰 페이지로 보낸다.

| 마켓 | 링크 방식 | 설정 |
|---|---|---|
| 쿠팡(한국어 기본) | 검색 URL + `lptag`/`subid` (보조 수단 — 공식은 파트너스 사이트에서 만든 `link.coupang.com/a/...` 링크를 `MALL_PRODUCTS.links.coupang` 에 입력) | `VITE_COUPANG_LPTAG`, `VITE_COUPANG_SUBID` |
| Amazon.com(영어 기본) / Amazon.co.jp(일본어 기본) | 검색 URL + `tag` | `VITE_AMAZON_TAG_US`, `VITE_AMAZON_TAG_JP` |
| 楽天 | 생성된 어필리에이트 링크만 사용 | `MALL_PRODUCTS.links.rakuten` |

- 모든 링크에 "광고" 표시, 쿠팡 선택 시 파트너스 고지문("이 포스팅은 쿠팡 파트너스 활동의 일환으로…")을 그대로 표시한다.
- `VITE_MALL_ENABLED=false` 로 끌 수 있고, Poki/CrazyGames 빌드(`VITE_AD_PROVIDER`)는 포털 규정(외부 링크 금지) 때문에 **기본 꺼짐**. 스폰서 제품도 같은 이유로 포털 빌드에서는 숨긴다(`VITE_SPONSORS_ENABLED`).
- 외부 링크는 네이티브에서 `@capacitor/browser`(인앱 브라우저), 웹에서는 새 탭. 이벤트: `mall_open`, `mall_market`, `mall_click`(from: home/game/result/evidence), `mall_impression`.
- 운영 시 `MALL_PRODUCTS`(운영자 추천)와 스폰서의 `links`는 원격 설정(JSON)에서 받아오도록 바꾸는 것을 권장.

## 4. 출시 전 할 일

- AdMob 앱 ID 교체: `android/app/src/main/AndroidManifest.xml`, `ios/App/App/Info.plist` (현재 Google 샘플 ID), 광고 단위 ID `.env` (`VITE_ADMOB_*`).

- 어린이 이용 가능성: 세제 관련 표현은 안전 수칙 중심 유지(삼키기·혼합 금지), 스토어 연령 등급과 광고 설정(가족용 정책) 검토.
