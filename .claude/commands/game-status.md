읽기만 한다. 아무것도 고치지 않는다.

1. 현재 버전·빌드 번호(iOS·Android)와 마지막 커밋 5개.
2. 마지막 출시 이후 `main` 에 쌓인, 아직 스토어에 안 나간 변경(플레이어에게 보이는 것만).
3. `npx tsc --noEmit` 와 `npm test` 결과(e2e 는 돌리지 않는다 — 6분 걸린다. 마지막으로 통과한 커밋만 적는다).
4. 열려 있는 PR 과 `agent/*` 브랜치.
5. `ops/agent/reports` 의 가장 최근 보고서에서 승인 대기 항목.
6. 운영자가 지금 해야 할 일 3가지 이내(스토어 콘솔·Mac 작업 포함), 급한 순서로.

한국어 표 하나와 "지금 할 일" 목록으로 짧게 답한다.
