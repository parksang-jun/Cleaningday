# 명령 처리 2026-11-19 — 출시 국가·수익·광고 방향

> 명령: "지금 몇 개국에 출시가 되었고, 현재까지 수익이 어디가 가장 많이 났는지 알려줘. 그리고 광고를 이제 어떻게 해야 되는지 알려줘"
> 해석: ① 출시 국가 수 ② 국가별 수익 1위 ③ 광고 = 게임 속 광고(AdMob 수익) + 우리 게임 홍보 광고 둘 다.

## 1. 출시 국가 — **확인 안 됨**
| 플랫폼 | 확인된 사실 (근거) | 국가 수 |
|---|---|---|
| iOS | 1.0 빌드를 App Store 심사에 냄 → 심사 지적(2.1, 추적 허용 창) 대응 Build 6(커밋 e3ba7a2), 1.1 '새 버전'용 Build 9 준비(store-assets/release-notes-1.1.md) | 기록 없음. App Store Connect '가격 및 사용 가능 여부' 확인 필요 (기본값은 '모든 국가', 애플 기준 175개 국가·지역) |
| Android | Play 등록 자료(스크린샷·그래픽·답안)만 준비 완료(b719d4f). 본인 인증 완료(11-16 메일). 출시·비공개 테스트 기록 없음 | 0 (미출시로 판단) |

- Gmail: 최근 15일 App Store 승인·판매 개시 메일 0건(애플 메일이 다른 주소로 갈 수 있음).
- 다른 팀 기록(영업 11-18 보고서)도 "출시 전, 지표 없음"으로 적고 있음.

## 2. 수익 — **데이터 없음**
- `state/ledger.csv`: 수익 0원(10월), 비용 Google Play 등록비 US$25(11-12)만 있음.
- `state/metrics/` 없음, AdMob 수익 메일 0건. 에이전트는 AdMob·App Store Connect에 로그인할 수 없어 국가별 수익을 조회하지 못함.
- 쿠팡·Amazon 제휴 수익: 계정 미가입으로 0원 확정.
- → 결재 `revenue-data-export` 로 자료 요청. 받으면 국가별 표를 만듭니다.

## 3. 광고 — 이제 이렇게
**A. 게임 속 광고(AdMob 수익)**
1. **app-ads.txt 올리기가 1순위** — 파일은 준비됐지만(PR #12) 올릴 곳이 없어 AdMob이 광고를 제한할 수 있음. 결재 `app-ads-host`(A안: parksang-jun.github.io, 5분, 무료).
2. 국가별 수익 자료를 받아 단가 높은 나라를 확인(`revenue-data-export`).
3. '광고가 길다' 불만: 1.1 에 40코인 건너뛰기 반영(Build 9). 광고 길이·횟수는 AdMob 설정 → 결재 `interstitial-video-setting`(권장: 빈도 제한만).
4. 1.1 제출, Android 비공개 테스트(12명·14일) 시작 → 출시 국가가 늘어야 수익도 늚.

**B. 우리 게임 홍보 광고**
- 결정(11-14 `ad-paid-budget`)대로 **유료 광고는 아직 안 함**. 리텐션 D1 30%·D7 10% 확인 후 다시 결재.
- 지금 할 일: 홍보용 SNS 계정 개설(결재 `ad-channels`) → 광고팀이 매주 숏폼 소재 제작, 사장님이 게시.
- 스토어 검색 최적화(ASO): 등록 자료는 준비됨.
