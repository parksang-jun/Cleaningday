# 틱톡 캡션·해시태그 (2026-11-26)

원칙: 해시태그는 5~6개. 넓은 것 2 + 장르 2~3 + 고유 1. 캡션 첫 줄은 질문이나 한마디로 짧게.
프로필 링크가 열리기 전까지는 "App Store에서 '싹싹 클린' 검색"으로 안내한다.
