# 광고 소재 보관함 (광고팀 · 루틴 E)

우리 게임을 알리는 광고 소재를 소재마다 폴더 하나로 둔다. 목록과 상태는 `../state/creatives.csv`, 게시·캠페인은 `../state/campaigns.csv`.

```
ads/cr-YYYYMMDD-NN/
  brief.md      훅·포맷·길이·쓸 장면·채널
  script.md     초 단위 장면표(화면 / 소리 / 자막)
  captions.md   ko·en·ja 캡션, 해시태그, CTA
  *.png *.mp4   실제 게임 화면 스크린샷·녹화 (있으면)
```

## 상태 흐름
- 소재: `초안` → `검수대기`(사장님 확인·게시 대기) → `게시됨` → `승격`(유료 소재로) / `교체`·`보류`(사유)
- 캠페인: `계획` → `승인대기` → `집행중` → `종료` / `중단`(사유)

## 지키는 것
- 실제 게임 화면만. 플레이와 다른 장면 금지.
- 세제 혼합 소재는 "절대 섞지 마세요"로 끝낸다. 실제 세제를 섞는 실사 촬영 금지.
- 실제 브랜드·스폰서 제품은 계약·검수 전 노출 금지. 대가 있는 협업은 `#광고`/`#ad`/`#PR` 표기.
- 공개 게시·유료 게재·예산은 사장님이 한다(에이전트는 준비까지).
