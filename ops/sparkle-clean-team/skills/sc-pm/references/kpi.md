# KPI 게이트와 벤치마크 (초기 가정 — 자사 데이터로 갱신)

일반 모바일 게임 벤치마크는 jelly-blocks-team 2026-10 조사(장르 공통 수치)를 승계했다. 청소·ASMR 장르 전용 공개 벤치마크는 아직 확인하지 않았으므로 **웹 검색으로 확인 필요**. 출처별 편차가 크다.

## 승격 게이트 (소프트런치 → 글로벌)

| 지표 | 광고 전용(스테이지제 캐주얼) | 메타·스폰서 추가 후 | 근거 |
|---|---|---|---|
| D1 리텐션 | ≥ 35% | ≥ 40% | GameAnalytics 2025 상위 10% D1 ~40% |
| D7 리텐션 | ≥ 10% | ≥ 15% | 유료 UA 작동점 D7 ~18% |
| D30 리텐션 | ≥ 3% | ≥ 5% | 전 장르 중앙값 0.7~0.8% |
| 세션 | ≥ 3회/일, 4~8분 | 동일 | 스테이지 1개 25~55초 기준 세션당 5~10스테이지 가정 |
| 스테이지 퍼널 | 1→3 ≥ 80%, 1→6 ≥ 50%, 1→12 ≥ 25% | 동일 | 자사 가정(초기) |

## 게임 고유 지표

| 지표 | 정의 | 초기 목표 |
|---|---|---|
| 평균 별 | level_complete.stars 평균 | 2.2~2.6 (너무 높으면 도전감 부족) |
| 기준시간 초과율 | time > parSec 비율 | 20~40% |
| 표면 손상 경험률 | surface_harm 발생 스테이지 / 시작 스테이지 | 학습 효과 확인(초반 높고 후반 낮아야) |

| 중도 이탈 | level_quit / level_start, quit 시 clean% | < 15% |

## 스폰서 지표 (스폰서 도입 후, 이벤트 추가 필요)

- 노출 수(툴바·상점), 선택률 = sponsor_item_select / 노출, 근거 화면 조회율 = sponsor_evidence_view / 선택, 스폰서 아이템 사용 스테이지 클리어 수
- 광고주 리포트 형식은 `sc-sponsors` `references/advertiser-report.md`

## 광고 운영 벤치마크(장르 공통)

- RV 옵트인 40~70%(30% 미만이면 배치·보상 재설계), 완료율 90%+, 필레이트 95%+
- 전면 광고: 결과 화면에서 다음/재시도/메뉴 이동 시에만, 2스테이지·150초 간격, 첫 스테이지 제외(코드 기본값)
- eCPM(리워드, 2024~25 출처 혼재): 미국 $13~30, 한국 $7~22, 일본 $7~11, SEA $2~6 — 반드시 자사 데이터로 갱신
- 계절성: Q4가 Q1보다 +20~40%

## UA 벤치마크(장르 공통)

- 캐주얼 Android CPI: 미국 $1.5~3.5, 서유럽 $0.6~1.5, SEA $0.2~0.6
- 광고 전용 LTV90 $0.20~0.55 → Tier 1 유료 UA 불성립 가능성. 유료 UA 조건: LTV:CPI ≥ 1.4, D7 ROAS 30~50%
- 설치의 상당수가 스토어 검색 → ASO 우선
