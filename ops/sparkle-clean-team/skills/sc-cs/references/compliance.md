## 아동·연령 (청소 게임 특유 리스크 — 출시 전 결정)
- 결정: 아동 포함 타깃 / 일반(13+) 타깃 중 택1, 근거 기록(PM·`sc-ads` 공유)
  - 아동 포함: Google Play Families 정책(인증 광고 SDK·광고 콘텐츠 제한), Apple Kids 카테고리 규정, 미국 COPPA, 한국 아동 개인정보(만 14세 미만 법정대리인 동의 관련 규정 — 적용 범위 확인 필요). 브랜드 스폰서·외부 링크 제약이 커짐
  - 일반 타깃: 아동 유입 징후(리뷰의 "우리 아이", 학교 언급 등) 모니터링 → PM 보고, 혼합 청중 판단 재검토
- 미국 주별 앱스토어 연령확인법(승계 정보: TX 시행, CA·UT·LA 2027 시행 예정 — 날짜 재확인), Apple Declared Age Range·Play Age Signals API 수신 여부 `sc-dev` 와 검토
- 세제·화학 제품 광고를 아동에게 직접 소구하는 문구·연출 금지(아동 대상 광고 자율규약·플랫폼 정책 확인 필요)

## 안전 메시지 (게임이 가르치는 내용 — 실제와 일치해야 함)
- [ ] 위험 혼합 모달(`hazardText`) 3개 언어: "염소계 + 산성 혼합 시 유독가스, 절대 섞지 말고 헹구고 환기" 유지
- [ ] 게임 규칙은 염소계↔산성만 감지하지만, 현실 안내는 "염소계는 다른 세제와 섞지 말 것"으로 더 넓게(암모니아 계열 등과의 혼합도 위험) — CS 답변·마케팅 문구 기준
- [ ] 표면 손상 힌트(솔-유리/도장, 강한 세제-원목, 고압세척기-실내)는 일반 상식 수준이며 제품별로 다를 수 있음 → 스폰서 제품은 라벨 주의사항을 그대로 반영
- [ ] 의료·응급 조언은 하지 않고 공식 기관 안내만(국가별 연락처 웹 확인)

## 광고 표시·스폰서(브랜드 제휴)
- [ ] 모든 스폰서 아이템에 "광고"(en Ad, ja 広告) 라벨 — 툴바·상점·근거 화면(코드 구현됨, 회귀 테스트 유지)
- [ ] 스토어 설명·처리방침에 브랜드 제휴 아이템 포함 고지
- [ ] 표시광고법(표시·광고의 공정화에 관한 법률): 사실·수치 광고에 대한 실증 책임 — 게임 속 성능 = 광고주 성적서 환산이므로 성적서·프로토콜 원본 보관, 우월·최고·1위 등 비교 표현은 근거 범위 밖이면 금지. 해당 조항·공정위 실증 고시의 세부 요건은 **확인 필요**
- [ ] 비교 표시·광고(기준 제품 대비 %): 비교 대상이 "일반 기준 제품(무브랜드)"임을 명시하고 경쟁사 실명 비교 금지. 비교광고 관련 공정위 심사지침 **확인 필요**
- [ ] 생활화학제품(세정제·곰팡이 제거제 등) 광고 표현: 화학제품안전법상 안전확인대상생활화학제품·살생물제품 관련 표시·광고 제한 표현(예: "무독성", "무해", "친환경" 류, 살균·항균 효능 표현의 승인 요건 등) 존재 가능 — **적용 여부·금지 문구 목록 확인 필요**, 광고주 측 법무 확인서 요청
- [ ] SNS 협찬 표시: 공정위 추천·보증 등에 관한 표시·광고 심사지침(`#광고`/`#협찬` 위치·방식) — 현행 요건 **확인 필요**
- [ ] 웹 포털(Poki/CrazyGames)의 제3자 광고·브랜드 노출 허용 여부 — 확인 전 포털 빌드 스폰서 비활성
- [ ] 스토어(Google Play·App Store) 브랜드 콘텐츠·광고 정책과 스폰서 아이템 충돌 여부 **확인 필요**
