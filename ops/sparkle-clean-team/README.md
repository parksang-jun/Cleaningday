# Sparkle Clean 운영팀 (sparkle-clean-team)

캐주얼 청소 게임 **Sparkle Clean**(한국어명 **싹싹 클린**, 작업명·미확정)을 2027년에 웹 포털과 Google Play·App Store에 출시하고 운영하기 위한 업무를 8명의 담당으로 나눈 플러그인입니다. Jelly Blocks(블록 퍼즐)를 대체하는 신작용입니다.

게임 요약: 12개 스테이지(거실 바닥 → 봄맞이 대청소)에서 먼지·진흙·기름때·얼룩·물때·곰팡이를 표면(원목·타일·스테인리스·유리·도기·패브릭·석재·차량 도장)에 맞는 도구 5종과 세제 4종으로 닦아 95% 이상 깨끗하게 만들면 클리어. 잘못된 도구는 표면을 손상시키고, **염소계 + 산성 세제를 섞으면 위험 혼합 경고**가 뜹니다. 수익은 광고(보상형·전면) + 향후 **실제 청소용품·세제 회사의 스폰서 아이템** — 스폰서 아이템은 광고주가 제출한 **시험 성적서 그대로** 게임 속 성능이 정해지고(기준 제품 대비 0.5~1.8배), 항상 "광고" 표시와 근거 화면이 붙습니다.

## 팀 구성과 호출 방법

| 담당 | 호출 | 시키는 일 예시 |
|------|------|----------------|
| 운영총괄 PM | `/sc-pm` | "다음 뭐 해야 해?", "주간 점검", "출시 준비 어디까지 왔어?" |
| 게임개발·릴리스 | `/sc-dev` | "이 버그 고쳐줘", "스테이지 13~20 추가", "AAB 빌드 절차", "스폰서 노출 이벤트 붙여줘" |
| 라이브옵스·밸런스 | `/sc-liveops` | "물때 스테이지가 너무 길어", "코인·상점 가격 조정안", "시즌 대청소 이벤트 기획" |
| 광고수익화 | `/sc-ads` | "AdMob 세팅 체크리스트", "코인 2배 광고 옵트인 왜 낮아?", "Poki 제출" |
| 광고·마케팅 | `/sc-marketing` | "인스타 릴스 ASMR 2주 캘린더", "틱톡 광고 캠페인 짜줘", "스토어 설명 ASO" |
| 데이터분석 | `/sc-analytics` | "이번 주 리포트" (CSV 첨부), "게이트 통과했어?", "스테이지별 이탈 분석" |
| CS·정책 | `/sc-cs` | "이 리뷰 답변 써줘" (리뷰 붙여넣기), "아이가 세제 섞어도 되냐고 물어봤대", "규제 체크" |
| 브랜드 제휴·스폰서 | `/sc-sponsors` | "세제 회사 제안서 써줘", "이 성적서로 게임 성능 환산해줘", "스폰서 라이브 전 검수", "광고주 월간 리포트" |

슬래시 명령 대신 자연어로 말해도 됩니다 — "청소 ASMR 릴스 만들어줘"라고 하면 광고·마케팅 담당이, "세제 회사에 보낼 제안서"라고 하면 스폰서 담당이 나섭니다.

## 추천 워크플로우 (2027 출시 로드맵)

1. `/sc-pm` — 앱명·appId(`com.sparkleclean.app`)·계정 확정, 로드맵 현재 단계 진단
2. `/sc-dev` + `/sc-liveops` — 스테이지 확장(12 → 소프트런치 전 목표치), 밸런스 봇 테스트로 기준시간 검증
3. `/sc-ads` + `/sc-dev` — AdMob·포털 계정 세팅, 매니페스트/Info.plist 실제 앱 ID, 웹 포털 제출 빌드
4. `/sc-marketing` — 청소 ASMR 숏폼 티저(전/후·소리), ASO 리스팅
5. `/sc-analytics` — 이벤트 연결(Firebase/GA4), 소프트런치 게이트 판정
6. `/sc-sponsors` — 게이트 통과(DAU 근거 확보) 후 청소용품·세제 광고주 영업, 성적서 기반 온보딩, 라이브 전 검수(샘플 브랜드 제거)
7. `/sc-cs` — 출시 후 리뷰·문의·안전 문의·정책 대응 루틴

## 권장 세팅

- **주간 운영 점검 예약 작업**: 플러그인 설치 후 "매주 월요일 아침에 `/sc-pm` 주간 점검 리포트를 예약해줘"라고 요청하면 PM이 로드맵·지표·정책·스폰서 파이프라인을 점검해 이번 주 액션을 제안하는 Claude 예약 작업이 등록됩니다.

## 참고

- 수수료·eCPM·광고 단가·스폰서 요율·플랫폼 정책은 변동되거나 아직 정해지지 않았습니다. 각 담당은 답변 전 웹 검색으로 최신 값을 확인하도록 설계되어 있고, 플러그인 안의 요율·법 조항 번호 자리는 `TODO`/`확인 필요`로 비워 두었습니다. **사용 전 반드시 웹 확인**하세요.
- 표시광고법(실증책임)·생활화학제품 표시 규제·개인정보·등급분류·아동 보호 등 법률 사안은 정보 제공용이며, 실행 전 전문가(변호사·공인시험기관) 확인을 권합니다.
- 예시 브랜드(BrightMax, AquaJet, 그리고 문서 속 예시)는 모두 **가상**입니다. 실제 회사명을 예시·샘플로 쓰지 않습니다.
